# GBA 36 色调色板版本演进与调整日志 (Palette Changelog)

本文档记录 `gba_avatar_hair_balanced_36` 调色板在演进与标杆对齐过程中的所有色槽微调与优化历史。

---

## v3 版本全局均衡调整 (`gba_avatar_hair_balanced_36_v3_all`)

**概要**：全发色全局均衡 36 色色板（修复绿偏蓝、红偏粉、蓝过渡及紫色发乌问题）。

### 1. 紫发体系色彩优化 (Purple Adjustments)
- `#52B539` (0px 死色) $\rightarrow$ `#6329BD`（二次元亮紫中色阶 / 高光）
- `#8C9CBD` (冗余灰蓝) $\rightarrow$ `#421084`（皇家深紫核心主体阶）
- `#6B5294` (浑浊灰紫) $\rightarrow$ `#180852`（午夜暗紫深阴影阶）

### 2. 全发色全局色槽修正 (Global Color Adjustments)
- `#185A42` (非标人工暗绿) $\rightarrow$ `#529484`（GBA 256 翡翠绿主色阶，消灭天青偏色）
- `#4A4A73` (低效灰蓝紫) $\rightarrow$ `#21636B`（GBA 256 深绿暗阴影阶）
- `#8C4A39` (泥褐重复色槽) $\rightarrow$ `#B5106B`（GBA 256 宝石深赤红阶，消除玫粉跳变）
- `#18BDF7` (过亮天青弱槽) $\rightarrow$ `#0884D6`（GBA 256 蔚蓝正蓝阶，强化蓝发主体）

## v3.1 色板排布规范优化 (Palette Layout & Structure Update)

- **黑白双色独立首行**：纯黑 `#000000` (#0，用于绝墨描边/轮廓) 与纯白 `#FFFFFF` (#1，用于画布底色/橡皮擦) 独立置于色板区第 1 排，与具体彩色发色色阶彻底解耦，不与其它颜色混杂。
- **中性灰阶分类提纯**：中性暗阶与银灰发色阶（#27、#3、#4、#30、#5、#7）归为独立的「中性」色系排在第二行，发色梯度纯粹连贯。
- **精简交互面板**：移除冗余的独立橡皮白卡片，全 36 色色块整齐平铺，支持左键前景色、右键背景色统一交互。

## v3.2 金色发色卡暗部优化 (Gold Hair Ramp Refinement)

- **金色发色卡暗色微调**：将金色发色卡第 1 阶（暗色 / 绝墨轮廓阶）由 `#3A2016` (#27 暖黑巧) 调整为 `#6B0818` (#29 暗血红)。
  - **视觉提升**：29 号色带有微红底蕴，在作为金发暗部勾边与闭塞阴影时，更能衬托金黄发丝（#8 暖褐 -> #35 琥珀金 -> #11 亮金）的灿烂色泽，呈现更具二次元动漫感的高反差金发光影。
## v4.0 调色板序号连续化与色相环流序重构 (v4.0 Palette Reordering & Sequential Indexing)

**概要**：重构 36 色色板顺序与色槽序号，彻底摒弃混乱的历史跳号，不考虑历史序号兼容，建立 0~35 严格单调递增的连续序号体系与色相环自然流序（方案 A）。

### 1. 结构与流序设计 (Chromatic Flow Architecture)
- **色相环自然流向**：按 `基础 (0~1, 255) -> 中性 (2~6) -> 肤色 (7~9) -> 暖色向 (绯红 10~13 -> 金棕 14~18) -> 冷色向 (青翠 19~22 -> 蔚蓝 23~26) -> 过渡色向 (魅紫 27~29 -> 粉樱 30~35 -> 回归绯红)` 自然延展，契合美术选色认知直觉。
- **序号完全连续单调递增**：所有色系内部的色槽 index 严格连续无跳号（从 0 到 35 零间隙），彻底根除历史版本中混杂错乱的跳跃编号（如旧版粉色混有 #31、#19、#9、#17 等）。

### 3. 色阶明度单调性修正 (Monotonicity Fix)
- **粉樱阶次序校准**：修正了旧版中 `#FFA5B5` (明度 193.7) 误排在 `#DE8C94` (明度 165.4) 之前的问题，现粉樱阶严格按明度升序排列（`#30 ~ #35`），使选区色彩统计与选色工具更直观。

## v1 / v2 历史基础色板说明

- **硬件规范**：RGB555 颜色空间（15-bit 色彩度）
- **发色体系**：覆盖黑、棕、金、粉、蓝、银白、绿、紫、红 9 大发色体系，平均单图像素色彩降幅 > 77%。
